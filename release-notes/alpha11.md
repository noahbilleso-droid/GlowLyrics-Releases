# GlowLyrics 2.0.0-alpha.11

Alpha 11 activates the live GitHub Releases update channel.

## Highlights
- Checks `noahbilleso-droid/GlowLyrics-Releases` for newer alpha releases.
- Downloads installers over HTTPS.
- Verifies SHA-256 before installation.
- Installs silently and relaunches GlowLyrics automatically.
- Keeps the native C# / WebView2 architecture with no PowerShell backend.

Alpha 11 is the final bootstrap install. Future alpha releases can be discovered from inside GlowLyrics.
