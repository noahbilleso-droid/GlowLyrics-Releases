# GlowLyrics Releases

Official public release and update channel for the GlowLyrics Windows desktop app.

- Channel: **alpha**
- Updater: **GitHub Releases**
- Installer verification: **SHA-256**
- Runtime backend: **native C# / WebView2**

The application checks this repository for newer GlowLyrics releases and can download, verify, install, and relaunch updates automatically.
